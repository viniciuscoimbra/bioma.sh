# De onde vem este design system

`@refy/ui` nasceu no projeto Dommus e está aqui como cópia versionada, sob
Apache-2.0 (ver `LICENSE`).

A cópia existe porque a tela precisa do pacote na hora de construir e ele ainda
não está publicado num registro. Quando estiver, esta pasta sai e o
`tela/app/package.json` passa a apontar para o pacote publicado.

Enquanto a cópia existir, mudança de componente é feita na origem e trazida
para cá. Duas cópias divergindo são defeito.
